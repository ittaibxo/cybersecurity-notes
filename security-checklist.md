# Personal Security Checklist

## Password Security
- [ ] Use unique passwords for each account
- [ ] Minimum 12 characters
- [ ] Mix of uppercase, lowercase, numbers, symbols
- [ ] Use a password manager
- [ ] Enable 2FA/MFA everywhere possible

## Network Security
- [ ] Use VPN on public WiFi
- [ ] Check for HTTPS on websites
- [ ] Keep router firmware updated
- [ ] Change default router passwords
- [ ] Disable WPS on router

## Device Security
- [ ] Keep OS updated
- [ ] Install security updates immediately
- [ ] Use antivirus software
- [ ] Enable firewall
- [ ] Encrypt hard drive

## Social Engineering Prevention
- [ ] Verify sender before clicking links
- [ ] Don't share personal info on social media
- [ ] Be suspicious of urgent requests
- [ ] Verify phone calls claiming to be support
